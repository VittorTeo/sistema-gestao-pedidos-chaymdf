# Sistema de Gestão de Pedidos - ChayMDF

Projeto Extensionista desenvolvido para a disciplina de **Programação Básica Aplicada** do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas da **Universidade Evangélica de Goiás (UniEVANGÉLICA)**[cite: 1, 2].

## 📌 Sobre o Projeto
O **Sistema de Gestão de Pedidos ChayMDF** é uma aplicação web leve e interativa desenvolvida para automatizar e organizar o fluxo operacional da empresa **ChayMDF**, situada em Anápolis-GO[cite: 1, 2]. O software substitui o controle manual em papel por um painel digital em formato Kanban, facilitando o rastreio de pedidos de corte e artefatos em MDF desde o lançamento até a finalização.

## 🚀 Funcionalidades Implementadas (Sprint 01)
- **Painel Kanban Interativo:** Organização visual dividida em 3 colunas (*Lançamento*, *Andamento* e *Finalizados*).
- **Funcionalidade Drag and Drop:** Capacidade de arrastar e soltar os cartões de pedidos livremente entre as colunas utilizando o botão esquerdo do mouse.
- **Modal de Nova Comanda:** Formulário dinâmico para inserção de pedidos contendo:
  - Nome do Pedido
  - Descrição detalhada das peças em MDF
  - Quantidade
  - Tempo estimado para entrega

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da interface.
- **CSS3:** Estilização moderna, responsiva e profissional.
- **JavaScript (Vanilla):** Manipulação dinâmica do DOM e lógica de arrastar e soltar (*Drag and Drop*).
- **Git / GitHub:** Controle de versão e versionamento de código[cite: 1, 2].

## ⚙️ Como Executar o Projeto
Por se tratar de uma aplicação web otimizada para os computadores básicos da empresa (sem necessidade de servidores complexos)[cite: 1, 2], sua execução é direta:
1. Faça o download ou clone este repositório em sua máquina.
2. Certifique-se de ter o arquivo `index.html` na pasta principal.
3. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web moderno (Google Chrome, Microsoft Edge, etc.).
